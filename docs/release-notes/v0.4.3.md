The review chain editor now stops a model revo cannot use before it is written.

**Update:** the **Update** row in the popover, or
`curl -fsSL https://raw.githubusercontent.com/igor-batrakov/agents-usage/main/install.sh | bash`.

- Some Codex models take only effort levels revo does not pass, so a review cannot run with them. A reviewer with
  such a model gets a red mark and a note, and no effort levels are offered for it.
- Apply does not go ahead while a new reviewer or a changed model is one of these: the editor asks revo for the
  model lists once more and, if the model is still unusable, shows an error instead of a check that revo would
  refuse. A reviewer that already had the model before is only marked.
- Needs a revo that sends `unusable`; with an older one the editor works as before.

`SHA256SUMS` lists the checksums of both archives.
