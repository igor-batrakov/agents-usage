The review chain editor now keeps model lists current and offers only the efforts each model takes.

**Update:** the **Update** row in the popover, or
`curl -fsSL https://raw.githubusercontent.com/igor-batrakov/agents-usage/main/install.sh | bash`.

- Model lists are refreshed in the background at launch and when the Review chain tab opens. revo goes to the
  network only for lists older than a day. **Update model lists** still fetches them all.
- The effort list of a reviewer is the one its model takes (Gemini 4 Hydrogen and Neon offer `xhigh`, other
  Gemini models up to `high`). When you change the model and its effort is not available, the nearest one is
  set (`xhigh` becomes `high`): for a model picked from the menu at once, for a typed one at Apply, where the
  confirmation shows it.
- A reviewer whose model the provider no longer lists gets a warning mark next to the model. The model is not
  replaced: choose another one yourself.
- Needs a revo that sends `model_efforts`, `default_efforts` and `unavailable`; with an older one the editor
  works as before.

`SHA256SUMS` lists the checksums of both archives.
