Google Cloud no longer leaves a new result table behind every time you change the limit.

**Update:** the **Update** row in the popover, or
`curl -fsSL https://raw.githubusercontent.com/igor-batrakov/agents-usage/main/install.sh | bash`.

- The query result table in the export's dataset (`agents_usage_…`) now depends only on what goes into the
  query: dataset, project, service and period. Changing the limit or the "subtract credits" switch reuses the
  same table and the last answer instead of creating another table and running another query.
- Tables left by 0.4.0 after such changes are not used any more; you can delete the extra `agents_usage_*`
  tables in BigQuery.

`SHA256SUMS` lists the checksums of both archives.
