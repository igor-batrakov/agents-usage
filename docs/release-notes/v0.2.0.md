A Review chain tab for Revolver users.

**Update:** from 0.1.1 on, the app updates itself (the **Update** row in the popover). From 0.1.0:
`curl -fsSL https://raw.githubusercontent.com/igor-batrakov/agents-usage/main/install.sh | bash`.

- If you run code reviews with Revolver (`revo`), Settings → Review chain edits its chain of reviewers: order,
  on and off, model and effort, review rounds per commit and the review language. Apply shows what will change
  before anything is written.
- The popover shows the review limits revo has recorded. You can turn this off in the tab.
- The tab appears when `revo` is in `~/.local/bin`, `/opt/homebrew/bin` or `/usr/local/bin`. If it is somewhere
  else, choose it in Settings → General.
- The app changes the chain only through `revo apply` and never edits revo's files itself.

`SHA256SUMS` lists the checksums of both archives.
