A Vertex reviewer in the Review chain tab gets its own Google Cloud project.

**Update:** the **Update** row in the popover, or
`curl -fsSL https://raw.githubusercontent.com/igor-batrakov/agents-usage/main/install.sh | bash`.
The project row needs a revo that knows block projects (`pipx upgrade revolver-review`); with an older revo the
tab works as before, without it.

- A Vertex review is billed to a Google Cloud project. Until now that was whatever project gcloud was switched
  to. Now the reviewer can keep its own: type the project ID or pick it from your gcloud account's projects.
  **default (gcloud)** goes back to the old behavior.
- The project's name is shown next to its ID, and an ID that cannot be a Google Cloud project gets a warning.
- Apply shows the project change along with the other changes before anything is written.

`SHA256SUMS` lists the checksums of both archives.
