In-app updates and an About tab.

**Install or update from 0.1.0:** `curl -fsSL https://raw.githubusercontent.com/igor-batrakov/agents-usage/main/install.sh | bash`.
0.1.0 has no updater, so this one time the update goes through the script. From 0.1.1 on, the app updates itself.

- Once a day the app checks GitHub for a new release. When there is one, the popover shows a row with an
  **Update** button: it downloads the release, replaces the app where it is and restarts it.
- Settings → About: version, a manual update check, a switch to turn the daily check off, links to the project.
- The install script quits a running copy reliably and gives up on a stalled download instead of hanging.

`SHA256SUMS` lists the checksums of both archives.
