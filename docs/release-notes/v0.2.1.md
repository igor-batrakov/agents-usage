The Review chain tab finds revo on its own more often.

**Update:** the **Update** row in the popover, or
`curl -fsSL https://raw.githubusercontent.com/igor-batrakov/agents-usage/main/install.sh | bash`.

- If `revo` is not in `~/.local/bin`, `/opt/homebrew/bin` or `/usr/local/bin`, the app asks your login shell
  where it is (once per launch, when the settings window opens) and keeps the path if it is a working revo.
- If that does not find it either, Settings → General has a field for the path: paste it (`~` works) and
  press Return, or drop the file onto it. The file panel opens in your home folder. A path that is not revo
  gets a clear message instead of being taken silently.

`SHA256SUMS` lists the checksums of both archives.
