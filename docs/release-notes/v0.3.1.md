Antigravity is found where its installer puts it, and opening the popover no longer polls.

**Update:** the **Update** row in the popover, or
`curl -fsSL https://raw.githubusercontent.com/igor-batrakov/agents-usage/main/install.sh | bash`.

- agy is also looked up in `~/.gemini/bin`, where the Antigravity installer puts it, so it no longer shows
  "agy not installed" when there is no link to it on your PATH.
- Opening the popover shows the data you already have and does not poll the services. Polls run on the timer,
  on ↻ (⌘R), and to catch up after sleep, unlock, a limit reset or a language change.
- The refresh interval now counts from the last full poll, so a manual refresh moves the next scheduled one a
  whole interval later.

`SHA256SUMS` lists the checksums of both archives.
