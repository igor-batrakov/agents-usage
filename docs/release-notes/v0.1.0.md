First public release.

**Install:** `curl -fsSL https://raw.githubusercontent.com/igor-batrakov/agents-usage/main/install.sh | bash`,
or download the dmg/zip below. The app is ad-hoc signed, not notarized: after a manual download, allow it in
System Settings → Privacy & Security → Open Anyway. See the [README](https://github.com/igor-batrakov/agents-usage#install).

- Claude Code, Codex, Antigravity, GitHub Copilot, Cursor and Kimi Code limits, OpenRouter and Moonshot balances.
- Menu bar icon with a bar per service, popover (⌃⌥L), pace marker, desktop panel.
- Notifications at a threshold and on reset, at most once per window.
- Energy saver: no polling while the screen is locked, less often on battery.
- Several accounts per service, API keys in the macOS Keychain.
- English and Russian interface, switchable without a restart.
- Universal binary (Apple Silicon and Intel), macOS 15 or later.

`SHA256SUMS` lists the checksums of both archives.
