# Лимиты ИИ

Виджет в строке меню macOS: лимиты подписок Claude Code, Codex и Antigravity (agy) в одном стиле.

- **Строка меню** — по полоске на включённый сервис, сверху вниз в порядке списка. Длина — 5-часовое окно
  (или выбранное в настройках сервиса), цвет — самое напряжённое видимое окно: обычный, янтарный от 70%,
  красный от 90%. Другие виды: проценты числами или только самый напряжённый. Подсказка при наведении — проценты.
- **Поповер** по клику или по ⌃⌥L — все видимые окна: процент использования, время до сброса, план. Имя
  сервиса — ссылка на его страницу лимитов. Чёрточка на полоске — метка темпа: сколько времени окна прошло;
  заливка правее неё — расход быстрее, чем нужно, чтобы хватило до сброса. У Codex — число бесплатных сбросов
  и когда сгорит ближайший (ссылкой на страницу, где сброс активируется). Внизу: ↻ обновить (⌘R), пауза
  автообновления, панель вкл/выкл, настройки (⌘,), выход (⌘Q).
- **Уведомления** — окно дошло до порога (по умолчанию 90%) и такое окно сбросилось; не чаще раза за окно.
- **Окно настроек**:
  - *Общие* — автообновление и интервал (1/5/15/30 мин), экономный опрос, уведомления и порог, вид иконки,
    метка темпа, автозапуск, горячая клавиша (⌃⌥L / ⌃⌥U / нет);
  - *Сервисы* — список с порядком (перетаскиванием), вкл/выкл, «+» из каталога, «−»; у каждого сервиса —
    имя, каталог конфигурации для второго аккаунта (`CLAUDE_CONFIG_DIR`, `CODEX_HOME`), видимые окна,
    окно для строки меню, ссылка на страницу лимитов, кнопка «Проверить»;
  - *Панель* — режим (выкл / поверх окон / на столе), привязка к углу и отступ, непрозрачность, «сквозь клики»,
    сервисы на панели.
- **Плавающая панель** — перетаскивается (перетаскивание отменяет привязку к углу), крестик при наведении,
  правый клик — «Обновить», «Скрыть панель».
- **Обновление** — по таймеру, при открытии поповера (если данным больше минуты), после выхода из сна, сразу
  после сброса окна и вручную. Выключенный сервис не опрашивается; при выключенном автообновлении — только ↻.
  Экономный опрос (включён по умолчанию): пока экран заблокирован или дисплей спит, по таймеру не опрашивает,
  после разблокировки догоняет, если данные устарели; от батареи — раз в три интервала.

## Установка

```sh
./build.sh install    # собрать и положить в ~/Applications/Лимиты ИИ.app
```

Нужны только Command Line Tools (`xcode-select --install`), Xcode не требуется. macOS 15+.
Для автозапуска включить «Автозапуск» в настройках (приложение должно лежать в `~/Applications`).

## Откуда данные

Приложение пользуется входом, который уже есть в CLI, и ничего не хранит:

- **Claude Code** — OAuth-токен Claude Code из Keychain, запрос к тому же API, что у `/usage`.
- **Codex** — `codex app-server`, метод `account/rateLimits/read` (авторизацию держит сам Codex).
- **Antigravity** — `agy -p /usage --output-format json` (модель не запускается).

Токены приложение не обновляет: это делает сам CLI. Если токен Claude истёк, виджет покажет прошлые значения
и подсказку «запусти claude».

Все три API недокументированные: если сервис поменяет формат, в блоке появится ошибка, остальные продолжат
работать.

## Ресурсы

~17–23 МБ памяти (physical footprint), 0% CPU между опросами. Опрос: Claude ~0,5 с, Codex ~1 с, agy ~4 с,
параллельно.
